## Selected Work

### [Aero3D](https://github.com/Jyotiraditya1006/Aero3D)
Tactical Neural Reconnaissance (C4ISR) system engineered for the National Technical Research Organisation (NTRO, SIH 2026). Generates georeferenced, metrically scaled 3D point clouds from a single UAV video pass using Monocular Neural Depth Fusion (`Depth Anything V2`), dynamic artifact masking (`CLIPSeg`), and CUDA acceleration.

### [Atelier AI](https://github.com/Jyotiraditya1006/Atelier-AI)
An executive autonomous multi-agent career platform featuring two-way conversational voice guidance (*Alex*), a 10-minute automated background scout querying major platforms, deterministic ATS scoring (0–100), and automated recruiter revert tracking.

### [CodeLens](https://github.com/Jyotiraditya1006/CodeLens)
Autonomous code health analyzer and auto-remediation platform. Scans repository Abstract Syntax Trees (AST) and cyclomatic complexity, backed by a hybrid ML vulnerability classifier (**>99% accuracy across 10,000+ snippets**) and zero-config LLM patch synthesis with side-by-side Monaco editor review.

### [Aegis AI](https://github.com/Jyotiraditya1006/Aegis-AI)
Enterprise FinTech customer retention platform featuring a PyTorch Tabular ResNet with learned entity embeddings, graph-compiled **ONNX Runtime serving achieving 0.09ms P99 latency** (21.48x speedup, >13,800 QPS), Explainable AI (XAI) feature attribution, and autonomous retention dialogue agents.

### [VehicleIQ](https://github.com/Jyotiraditya1006/VehicleIQ)
Real-time vehicular diagnostics and predictive maintenance platform ingesting high-frequency OBD-II telemetry streams with TensorFlow LSTMs, Scikit-learn, an asynchronous FastAPI backend, and a reactive Next.js 14 diagnostic dashboard.

### [RecruitIQ](https://github.com/Jyotiraditya1006/RecruitIQ)
High-throughput candidate screening and ATS ranking engine utilizing NLTK POS keyword extraction, n-gram contextual coverage, and transformer-based semantic embeddings (`sentence-transformers`) paired with custom synthetic training data generators.

### [ApexPrep AI](https://github.com/Jyotiraditya1006/ApexPrep-AI)
Full-scale computer-delivered ETS GRE® and IELTS™ adaptive simulation platform featuring an authentic testing interface, procedural mathematical question engine, and a 2.58M+ word morphological vocabulary lexicon.

### [Weather-HMM-Predictor](https://github.com/Jyotiraditya1006/Weather-HMM-Predictor)
Probabilistic weather sequence forecasting and regime transition modeling implemented using Hidden Markov Models (HMM) and maximum-likelihood path decoding via the Viterbi dynamic programming algorithm.
